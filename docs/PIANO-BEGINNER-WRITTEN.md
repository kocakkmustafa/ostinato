Local candidate on accepted Ostinato `ed479f3075eb14178d3c1a66331518d3da41ef16`.
Entry: no prior notation; keyboard/piano covering C3–G4, comfortable supported seating.
Exit: key names/direction; hand-specific finger numbers; quarter/half/whole and paired eighths in 4/4; treble G4 and bass F3 anchors and middle C; separate hands, shared pulse, held/changing bass; original four-bar study; restart at a bar and choose a smaller practice task.

## Pedagogy recheck corrections

The original sixteen-lesson flow is retained. Lesson 2 needs two Cs within C3–G4, optional third only if available. Lesson 3 now locates actual middle C: fourth C from the left on an 88-key A0–C8 keyboard (24th white / 40th overall key); shorter keyboards require their manufacturer map / middle-C MIDI 60 reference, otherwise register remains uncertain. The original local keyboard vector is labeled; it is not a universal physical centre marker. Manufacturer octave labels are not treated as pitch proof.

Lessons 7/8 use original Flutter vector clefs, noteheads, stems, beams, rests and ledger lines. Lesson 14 now presents a two-bar grand staff without advance note-name answers; a separately expanded answer panel names notes, durations and start counts. Staff position descriptions provide accessibility without revealing pitch answers. Lesson 15 has the four-bar vertically aligned two-hand study. All score bars total four beats; LH held notes and melody onsets share a beat grid. Answers come from the same explicit score events that render the notes; tests separately check staff anchors and expected reading pitches.

Lesson 4 distinguishes a brief clap followed by count/wait from actually holding a half note on a key. Lesson 13 explicitly defaults to quarters. Lessons 15/16 require bar/count observation, one smaller correction, return to the same etude at the same chosen tempo, and comparison of the same location; unchanged, uncertain and no observed error remain honest outcomes.

Additional primary reference checked 2026-10-04: [The MIDI Association’s own response](https://midi.org/community/midi-specifications/midi-octave-and-note-numbering-standard) identifies middle C as MIDI note 60 and explains octave-number variation. This is a reference identifier, not a MIDI input or measured-pitch claim; no video/audio observation was conducted. The 88-key white/overall key indices are counted from standard A0 and the repeating keyboard layout, not copied artwork.
