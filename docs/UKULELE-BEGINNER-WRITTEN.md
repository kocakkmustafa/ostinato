# Ukulele written beginner foundation

Local authored product increment, based on the accepted piano source tree. Library → Ukulele → 18 ordered TR/EN lessons. This is a right-handed, four-string soprano/concert/tenor course for identified high-G GCEA strings (4→1: G4 C4 E4 A4), with C4 as middle C and string 3 the lowest sounding open string. Low-G and baritone setups require their own manufacturer guidance; users must not tighten an unidentified string set to an assumed octave. An external tuning aid is an entry requirement, not a supplied or verified app feature.

## Entry and exit

Entry: identify instrument/string setup, support the instrument comfortably, use the instrument manual and an external tuner/reference. No prior notation or chord knowledge is required. Left-handed setups are explicitly excluded rather than silently mirrored.

Exit task: identify string/fret/finger directions; decode four chord grids and a new two-bar tablature task; attempt C, Am, F and G7 changes in counted 4/4; distinguish down/up attacks, ringing holds and counted rests; attempt an original eight-bar study and compare a specific correction at the same chosen tempo. These are opportunities for practice and self-observation, not measured achievements or mastery approval. Another-day revisit is requested. No pass/fail, artificial score, timer completion, stored progress, AI observation, microphone or posture measurement is added.

## Curriculum map

| Lessons | Preparation → practice → self-check/recovery |
|---|---|
| 1–4 | Identify high-G variant, support safely, use an external tuner without assuming peg direction, learn strings/frets/fingers and chord-grid conventions |
| 5–6 | Single-string original note phrase, relaxed fretting, steady four-count pulse, ringing versus counted silence |
| 7–10 | C / Am / F / G7, individual-string checks, shared-finger transition and recovery from buzzing, muting or overgripping |
| 11–13 | Chord changes on bar boundaries, counted preparation space, D/U eighths, explicit R rest and H no-new-attack |
| 14–15 | New two-bar tab with separately hidden pitch answers, then create an original four-note bar |
| 16–18 | Pairwise preparation, original eight-bar chord/rhythm study, locate an error by bar/count and retry at the same tempo, another-day exit revisit |

The authoritative diagram data is packaged with the lesson text. Chord positions use string order 4→1: C 0003, Am 2000, F 2010, G7 0212. Fingers are index 1, middle 2, ring 3, little 4; 0 means open. Tab shows 1→4 from top to bottom, unlike the chord grid. The hidden tab answers identify each beat’s exact string/fret pair; pitches C4 D4 E4 F4 | G4 E4 D4 C4 are explanatory, not an unintroduced pitch-derivation objective. Each column is a quarter beat. The eight study bars each contain eight equal half-beat cells; H adds no attack and retains ringing or existing silence, R stops sound while counting. These are original exercises and original repo-native vector drawings, with no songs, downloaded images or audio.

## Primary verification, 2026-10-04

- [Fender, How to Play Ukulele](https://www.fender.com/articles/techniques/how-to-play-ukulele): manufacturer-authored beginner guidance for held instrument support, 4 G / 3 C / 2 E / 1 A, string 3 lowest and string 1 highest; finger/grid conventions; beginner C, F, Am, G7 and strumming topics. Checked page text, not embedded videos or paid lessons.
- [Fender, How to Tune a Ukulele](https://www.fender.com/articles/setup/how-to-tune-a-ukulele): confirms reentrant G and string-3 middle C. Its loose “low to high” wording is not adopted: physical order and pitch order are explicitly separated. Its alternate-size tuning paragraph is not used as setup advice.
- [Fender, How to Strum a Ukulele](https://www.fender.com/articles/techniques/how-to-strum-a-ukulele): relaxed wrist, thumb/index strokes, down/up directions and count-based rhythm. No song content copied.
- [Kala Learn to Play](https://kalabrand.com/pages/learn-to-play): official basics/tuning/chord learning resource and separate baritone path. No account, paid access or audio was used.

Unavailable linked Fender chord lesson pages and inaccessible Kala FAQ/Aquila URLs are not evidence. Named chord pitch classes are independently checked mathematically from the specified open pitches and fret semitones: C={C,E,G}, Am={A,C,E}, F={F,A,C}, G7={G,B,D,F}. The authored fingering and graduated pacing require independent pedagogical review; manufacturer web pages do not prove learning effectiveness.
