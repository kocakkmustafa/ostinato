# OST-UX-04 ekran görüntüsü dizini

Etiket: **test render, sahte veri** (ekranlarda "Prototype" rozeti görünür). Gerçek cihaz/simülatör görüntüsü değildir.
Üretici: `tool/ux_04_render_evidence_test.dart` (elle: `flutter test tool/ux_04_render_evidence_test.dart`; CI'a girmez). Yöntem `evidence/ux-01/render/` ile aynı: mantıksal 390x844, `devicePixelRatio` 3, PNG 585x1266, dil en, açık tema, paketli Hanken Grotesk / IBM Plex Mono. İşaretler (doğru, farklı nota, duyamadım) şekil olarak çizilir; bu yüzden kutu (tofu) çıkmaz.
Kurulum: `UxPrototypeScreen`, bayrak açılmadan doğrudan çizildi; gerçek gitar kurs kataloğu (`content/v1/gtr`) yolculuk 3'te kullanıldı; ağ, hesap, define, mikrofon, kamera yok.

Güncel simülatör görüntüleri: BLOCKED_ACCESS (define dosyası kurucu izni)
