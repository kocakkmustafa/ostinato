# Ostinato

**Enstrüman pratik koçu — tüm uygun çalgılara açık (ilk motor: çello).**

Kamera+mikrofonla postürünü ve temel tekniğini analiz eder; öğretmenin yanındaymış gibi sesli yönlendirir; öğretmensiz pratik saatlerini ölçülebilir kılar. Marka ve mimari TÜM uygun çalgılara açıktır.

Ortak ilke: on-device pose analizi + deterministik kural motoru — gerçek-zamanlı LLM yok, ham video cihazdan çıkmaz, düşük güvende hüküm yok, her karar açıklanabilir.
